# 🎬 CineScope - Modern Movie Discovery App

A responsive, feature-rich movie discovery web application built with **React**, **Vite**, and **Tailwind CSS**, powered by the **TMDB (The Movie Database) API**. 

---

## ✨ Key Features

- **Home & Explore**: 
  - Real-time movie search functionality.
  - Browse trending, popular, and comprehensive movie lists.
- **Dynamic Movie Details**: 
  - Detailed metadata including release date, ratings, runtimes, taglines, and overviews.
  - Responsive hero section utilizing high-res posters (desktop) and backdrops (mobile).
- **Interactive Multimedia & Sections**:
  - **Cast Grid**: View movie cast members with quick profile links.
  - **Social Section**: Explore user reviews and discussions.
  - **Media Hub**: Browse videos and watch YouTube trailers and clips instantly in an in-place modal.
  - **Recommendations**: Discover similar movies with dynamic matching scores.
- **Actor/Cast Profile Pages**:
  - Detailed actor view featuring biography, birthdays with auto-calculated age, gender mapping, and place of birth.
- **Smooth Navigation**: 
  - Integrated with `react-router-dom` and automated scroll-to-top behavior on route transitions.
- **Production Ready**: 
  - Configured for seamless deployment to **GitHub Pages** using GitHub Actions CI/CD pipelines.

---

## 🛠️ Tech Stack

- **Frontend Framework**: React 19 (via Vite)
- **Styling**: Tailwind CSS
- **Routing**: React Router DOM (`HashRouter` / `BrowserRouter`)
- **Data Source**: TMDB API (v4 Bearer Token Authentication)
- **Deployment**: GitHub Pages & GitHub Actions
